> **Назначение:** Пошаговое руководство для команды и ИИ-агента при получении реального датасета Sentinel-1 и Sentinel-2 (~45 ГБ) на площадке «КосмоХакатон 2026».

## 3. Двухфазная стратегия сабмита (Time-to-Submission)

### ФАЗА 1: Гарантированный сабмит за 10 минут (Track B — Физическая модель)
**Задача:** Защитить команду от любых технических сбоев, нехватки GPU и OOM, сразу отправив валидный результат в лидерборд.

1. **Принцип работы:** Физическая экспертная модель (`src/models/physical.py`) производит адаптивную фильтрацию Ли, динамический порог Оцу в $[-24, -11]$ дБ, ветровую компенсацию и непрерывный HAND-приор.
2. **Преимущество:** Считается на обычном CPU за ~15–30 секунд на пару без потребности в видеокарте.
3. **Защита $Spec\_base = 1.0$:** Модуль калибровки (`src/postprocessing/submission.py`) автоматически обнуляет паводок на 3 парах межени, гарантируя максимальный балл по специфичности.
4. **Формирование сабмита:**
   - Создаются `submission.csv` и маски `predictions/<pair_id>_flood.tif`.
   - Автоматически проверяется допуск расхождения площадей $\le 2\%$.
   - Первый сабмит готов к загрузке в проверяющую систему.

---

### ФАЗА 2: Глубокое обучение и ансамблирование (Track A — MultiModalHydrologyNet)
**Задача:** Выжать максимальный $Score$ за счет 15-канальной нейросети UNet с механизмом внимания.

1. **Предобработка и нарезка тайлов:**
   - Запуск генерации 15 каналов (`scripts/preprocess.py`).
   - Нарезка сверхбольших растров на окна $512 \times 512$ с шагом 256 (перекрытие 50%).
2. **Обучение с пространственной кросс-валидацией (LOAO):**
   - Использование генератора сплитов `Leave-One-AOI-Out` (`src/models/dataset.py`).
   - Обучение с функцией потерь `CombinedHydrologicalLoss`:
     $$Loss = 0.35 \cdot \text{Focal} + 0.45 \cdot \text{Lovasz-Hinge} + 0.20 \cdot \text{Boundary}$$
   - Включение Modality Dropout ($p = 0.4$) для устойчивости к облачности.
3. **Оконный инференс со сшивкой Ханна:**
   - Скользящий инференс с 2D Hann blending (`src/features/tiling.py`), гарантирующий отсутствие швов и скачков на границах тайлов.
4. **Гибридный ансамбль:**
   - Смешивание вероятностей Track A и Track B.
   - При облачности $> 70\%$ пайплайн автоматически переключается на чистый радарный режим.

---

### ФАЗА 3: Топологическая постобработка
Перед финальным расчетом площадей применяется топологический фильтр (`src/postprocessing/topology.py`):
1. **Удаление спекл-шума:** отсечение несвязных пятен $< 25$ пикселей ($0.25$ га).
2. **Геодезическое связывание речной сети:** восстановление непрерывности русла вдоль постоянной маски GSW (устранение разрывов на искусственных дамбах и мостах).
3. **Морфологическое сглаживание:** устранение пиксельной «гребенки» вдоль береговой линии.

## 4. Чеклист финальной валидации перед сдачей (QA Checklist)

Перед загрузкой архива в оргкомитет запустите валидатор:

```bash
# Валидация сформированного сабмита
python -c "
from src.metrics.validator import SubmissionValidator
v = SubmissionValidator('task/sample_submission.csv')
is_valid, errors = v.validate_submission('submission.csv', 'predictions')
print('Сабмит валиден:', is_valid)
if errors:
    for e in errors: print(' -', e)
"
```

**Критерии допуска:**
- [x] Ровно 11 строк в `submission.csv` (названия пар строго совпадают с каталогом).
- [x] $flood\_ha \le water\_peak\_ha$ во всех строках.
- [x] На 3 парах межени $flood\_ha = 0.0$ (сохранение $Spec\_base = 1.0$).
- [x] Ровно 11 файлов GeoTIFF в каталоге `predictions/`.
- [x] Все растры: формат `uint8`, значения строго $\{0, 1\}$, CRS `EPSG:32652`.
- [x] **Расхождение площадей по каждому району строго $\le 2\%$** (регламентный норматив).
- [x] Упаковка в архив: `zip -r submission.zip submission.csv predictions/`.

## 1. Описание задачи

Разработка программного комплекса для мониторинга паводковой обстановки в бассейне рек **Амур** и **Зея** (Амурская область). Комплекс по разновременным спутниковым снимкам высокого разрешения определяет положение водного зеркала и выделяет зоны нового затопления, сохраняя работоспособность при сплошной циклональной облачности.

### Выходные артефакты по каждой паре:
1. `flood_ha` — площадь зоны нового затопления (га);
2. `water_pre_ha` — площадь водного зеркала до события (га);
3. `water_peak_ha` — площадь водного зеркала на пике паводка (га);
4. `predictions/<pair_id>_flood.tif` — бинарная растровая GeoTIFF-маска затопления (uint8, EPSG:32652).

---

## 2. Метрика оценки соревнования

Итоговый показатель качества рассчитывается по формуле:

$$\text{Score} = 0.45 \cdot Q_{\text{flood}} + 0.25 \cdot Q_{\text{water\_peak}} + 0.15 \cdot Q_{\text{water\_pre}} + 0.15 \cdot \text{Spec\_base}$$

Сходимость площади по каждой паре:
$$q = \max\left(0.0;\, 1.0 - \frac{|X_{\text{pred}} - X_{\text{true}}|}{\max(X_{\text{true}};\; \text{threshold})}\right)$$
- Порог для `flood_ha`: **50 га**
- Порог для водного зеркала (`water_peak_ha`, `water_pre_ha`): **200 га**
- $Q$ — среднее $q$ по 8 паводковым парам.

Штраф за ложные срабатывания на 3 парах межени:
$$\text{доля} = \frac{\max(0.0;\, \text{flood}_{\text{pred}} - \text{flood}_{\text{true}})}{\text{AOI\_area}}$$
$$\text{Spec\_base} = \text{mean}\left(1.0 - \min\left(1.0;\, \frac{\text{доля}}{0.005}\right)\right)$$
*(Ложное затопление свыше 0.5% площади района полностью обнуляет компоненту Spec_base).*

**Жёсткий регламентный допуск:** Расхождение площади по растровой маске GeoTIFF и таблице `submission.csv` строго $\le 2\%$.

## 3. Результаты разработки

### Этап 0: Аудит данных, EDA, критика эталона и валидация
1. **Движок соревновательных метрик (`src/metrics/score.py`):**
   - Полная программная реализация $Score, Q_{\text{flood}}, Q_{\text{water\_peak}}, Q_{\text{water\_pre}}, Spec\_base$.
   - Точные пороги (50 га, 200 га, 0.5% AOI).
2. **Модуль валидации сабмита и растров (`src/metrics/validator.py`):**
   - Контроль схемы CSV (11 пар, неотрицательность, физическое ограничение $flood\_ha \le water\_peak\_ha$).
   - Проверка растров GeoTIFF (`uint8`, значения strictly $\{0, 1\}$, проверка $\le 2\%$ расхождения площади).
3. **Количественный EDA и профили сенсоров (`scripts/eda.py`):**
   - Полный каталог 11 пар (`reports/eda_summary.json`).
   - Расчет площадей AOI ($1024 - 1600 \text{ км}^2$), классового дисбаланса (доля паводка всего $1.052\%$ от AOI) и временного лага S1-S2 (до 5.0 суток).
4. **Глубокий критический анализ эталона (`reports/eda_and_ground_truth_critique.md`):**
   - Подробный разбор 5 дефектов синтетического эталона (ветровая рябь, double-bounce в лесу, замутненность $NDWI \le 0$, артефакты $HAND = 25$ м, лаг съемок до 5 дней) с математическими решениями для нейтрализации в ML-пайплайне.
5. **Синтетический верификационный бенчмарк (`scripts/make_synthetic_benchmark.py`):**
   - Генератор эталонных геоданных и масок для автономного сквозного тестирования без необходимости скачивания тяжелых растров.

### Этап 1: Геопространственный пайплайн предобработки и генерации признаков
1. **Радиолокационная ветвь Sentinel-1 (`src/features/sar.py`):**
   - Адаптивный фильтр Refined Lee (в физической линейной шкале интенсивности без логарифмического смещения).
   - Дифференциальный временной признак $\Delta\sigma^0_{VV} = \sigma^0_{VV,\text{peak}} - \sigma^0_{VV,\text{pre}}$ (дБ).
   - Кросс-поляризационный признак $Ratio_{VH/VV} = \sigma^0_{VH} - \sigma^0_{VV}$ (дБ) для разделения double-bounce в затопленном лесу и открытой воды.
   - Маска радиотеней и наложений на основе ЦМР и порога шума сенсора.
2. **Оптическая ветвь Sentinel-2 (`src/features/optics.py`):**
   - Фильтрация облаков и теней по слою классификации сцены ($SCL \in \{3, 8, 9, 10\}$).
   - Расчет спектральных индексов: $MNDWI$ (подавляет асфальт и застройку, устойчив к взвесям), $NDWI$, $NDVI$, $AWEIsh$ (подавление горных теней).
   - Детектор пригодности оптики ($is\_optical\_valid$) и доли облачности для безопасного перехода на чисто радарный режим.
3. **Вспомогательный геофизический стек (`src/features/terrain.py`):**
   - **Непрерывный логистический приор HAND:** $P(\text{flood} \mid HAND) = \frac{1}{1 + \exp((HAND - H_0) / \tau)}$ ($H_0 = 12$ м, $\tau = 3.0$ м), устраняющий ступенчатые артефакты жесткого среза $25$ м на террасах.
   - Карта уклонов (Slope в градусах) через оператор Собеля для отсечения гравитационно невозможных зон затопления.
   - Маска постоянной воды JRC GSW ($\ge 80\%$) для исключения фоновых водоемов из нового паводка.
   - Маска застройки WorldCover (код 50) для устранения ложной воды на зеркальном асфальте и бетоне.
4. **Сборка 15-канального мультимодального тензора (`src/features/pipeline.py`):**
   - Унифицированный интерфейс сборки полного тензора признаков размером $(15, H, W)$ со всеми метаданными.
5. **Потоковая оконная нарезка и 2D Hann-сшивка (`src/features/tiling.py`):**
   - Нарезка сверхбольших сцен на тайлы $1024 \times 1024$ (или $512 \times 512$) со скользящим шагом и перекрытием.
   - Сшивка растра взвешиванием через двумерное косинусное окно Ханна (Hann Blending), гарантирующая отсутствие швов и скачков на границах окон.
6. **Набор модульных тестов (`tests/`):**
   - 24 комплексных теста, проверяющих математику фильтров, индексов, приоров, сшивки окон и соревновательных метрик (`24 passed in 0.70s`).
7. **Консольный скрипт предобработки (`scripts/preprocess.py`):**
   - Автоматическая обработка и аудит признаков по всем 11 парам (`reports/preprocessing_audit.json`).

## 5. Быстрый старт и запуск тестов

### Локальный запуск:
```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск полного набора тестов
python -m pytest tests/ -v

# Запуск EDA анализа
python scripts/eda.py

# Генерация тестового бенчмарка и сквозная проверка метрики
python scripts/make_synthetic_benchmark.py
```

### Запуск через Docker (автономно):
```bash
docker compose up --build
```
